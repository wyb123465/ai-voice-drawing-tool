# XEngineer 提交说明

## 项目信息

- 参赛题目：第四批次议题二，AI 语音绘图工具。
- 项目名称：AI 语音绘图工具 / 声绘工作台。
- 核心目标：用户不使用鼠标或键盘，只通过语音完成绘图创作、对象编辑、撤销重做、清空和导出。
- 部署地址：https://wyb123465.github.io/ai-voice-drawing-tool/ （推送到 `main` 且 GitHub Pages Actions 成功后可访问）
- Demo 视频：待录制后替换为 B 站或云盘链接，并同步填写到 README 与提交平台。
- 设计文档：[docs/design.md](./design.md)

## 用户价值与创新点

- 目标用户：不方便精细操作鼠标键盘、需要快速表达画面构思，或在演示/课堂中希望用自然语言生成草图的人。
- 核心痛点：传统绘图工具依赖工具栏、图层和快捷键，用户需要先学习操作方式；语音场景下还容易遇到识别错误、复杂句拆解失败和误操作已有对象的问题。
- 解决方案：把中文语音转为结构化绘图命令，由本地规则优先解析，低置信度才进入可选 LLM 兜底；所有云端输出再经白名单校验，最终落到 Canvas 可执行的安全命令。
- 创新点：支持一句话复合场景拆解、相对布局、序号对象选择、未知对象阻断、无密钥 LLM 链路演示，以及无麦克风文本回放，方便评审复现。

## Demo 视频建议脚本

1. 打开页面，点击“启动语音”，授权麦克风。
2. 说：“画一个太阳，下面有两座山，山前面有一棵树。”
3. 说：“在左上角写上 XEngineer。”
4. 说：“把背景改成浅蓝色。”
5. 说：“画一个红色圆，再画一个蓝色圆，再画一个绿色圆。”
6. 说：“删除第二个圆。”
7. 说：“写上再见。”
8. 说：“画一只猫。”并打开 `?llmdemo=1` 展示云端兜底模拟链路。
9. 说：“撤销上一步。”再说：“重做。”
10. 说：“导出图片。”

## 评分点对应

- 指令理解准确性：支持颜色、形状、位置、相对布局、复合场景、序号选择、颜色筛选、焦点指代、指代+形状交叉验证和未知对象阻断。
- 容错性：未识别或未知对象不会误改画布；“写上再见”不会被错误拆分；“删除第二个圆”作用于第 N 个匹配对象；“园/元/兰色/桔色”等常见 ASR 偏差可被纠正；“整个三角形上去”“把它上去”“把这个圆上去”这类低置信表达会先澄清确认再执行，“把那个圆挪上去”可直接解析为焦点圆移动；点名不存在的形状不会进入澄清、误画或执行缩放/换色。
- 响应延迟：默认本地规则解析，不配置密钥时不调用云端；Canvas 只在状态变化后重绘。
- 复杂指令拆解：支持“画一个太阳，下面有两座山，山前面有一棵树”和“画一个红色圆再画一个蓝色矩形”。
- 云端能力与成本控制：可选 OpenAI 兼容兜底，低置信度才触发；返回命令经过白名单校验；提供 `llmdemo=1` 本地模拟链路用于无密钥演示。
- 评审可复现性：右侧“运行评审演示”可一键覆盖复合场景、文字、背景、澄清追问、序号选择、云端兜底模拟、撤销重做和导出链路；运行看板实时展示对象数、历史步数、解析来源和最近动作；AI 兜底面板会明确展示当前 LLM 模式。
- 工程可靠性：66 个自动化测试覆盖命令解析、状态引擎、渲染器、LLM 兜底、OpenAI resolver、demo 回放、澄清追问和评审脚本数据。

## PR 交付规范

后续真实改动建议全部从分支发起 PR，并使用仓库内的 `.github/pull_request_template.md`。每个 PR 只做一件事，例如：

| PR | 范围 | 必填测试 |
| --- | --- | --- |
| 提交材料补强 | README、提交说明、设计文档、LICENSE、PR 模板 | `npm test` |
| 演示与部署修复 | GitHub Pages workflow、demo 回放入口 | `npm test`，在线地址 200 |
| 视频链接回填 | README 与提交平台链接 | 匿名窗口打开视频链接 |

每个 PR 描述至少包含：标题、功能、实现思路、测试结果。不要修改 commit 时间戳；把实际发生的补救工作拆成真实、可审查的提交即可。
